# Intermediate Water Salinification Counteracts Thermosteric Sea-Level Rise in the Tropical Southwest Indian Ocean

Code for reproducing the analysis associated with this study.

## Authors

- JongHun Han
- SungHyun Nam
- Hanna Na

## Contents

The `01_Code/` directory contains the analysis scripts.

## Data availability

Input datasets are not included in this repository. Obtain the relevant datasets from their original providers and place them in the paths specified by the scripts.

## Usage

Prepare the required input data, then run the scripts in `01_Code/` in the appropriate analysis order.
